# Quiz, Assessment and Readiness Model

Questions support MCQ, true/false, ordered workflow, scenario, next-action and incorrect-status identification. Questions reference actual ERP screens and system behavior.

Attempts persist server-side with last/best score, pass state and wrong question IDs. Wrong topics feed learner recommendations.

Readiness combines required lessons, tours, practice, module quizzes, workflows and final role assessment using configurable weights and thresholds. Practice and the final assessment are hard gates: quiz scores alone cannot make an employee Ready.

Statuses: **Not Started → Learning → Practising → Assessment Pending → Ready**.
